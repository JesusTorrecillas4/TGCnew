# ADR-001: Base de dades del projecte
## Context
Necessitem una base de dades flexible per a emmagatzemar productes, usuaris i
comandes amb relacions no rígides.
## Decisió

Farem servir MongoDB com a base de dades principal del projecte.

MongoDB s'executarà mitjançant Docker, cosa que permetrà que tots els membres del projecte treballin amb una configuració similar de la base de dades.

## Conseqüències

# Positives

MongoDB permet treballar amb documents flexibles i fàcils d'adaptar.
És adequat per emmagatzemar productes amb característiques diferents.
S'integra bé amb Node.js i Express.
Docker facilita la instal·lació i posada en funcionament de la base de dades.
Permet afegir nous camps als productes sense haver de modificar una estructura rígida.

# Negatives

Les consultes amb moltes relacions poden ser més complicades que en una base de dades relacional.
Cal tenir cura amb l'estructura dels documents per evitar duplicar massa informació.
L'equip ha d'aprendre a treballar amb MongoDB i les seves eines.
