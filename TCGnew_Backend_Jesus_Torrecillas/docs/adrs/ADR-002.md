# ADR-002: Estructura inicial del projecte

## Context

El projecte consisteix en desenvolupar una botiga online de cartes TCG d'anime. El projecte tindrà diferents parts, com el frontend, el backend amb Node.js, la connexió amb MongoDB i la configuració de Docker.


## Decisió

Farem servir una estructura de monorepo, mantenint el frontend, el backend, la configuració de Docker i la documentació dins del mateix repositori.

L'estructura inicial serà aproximadament:

projecte-tcg/
├── frontend/
├── backend/
├── docker/
├── docs/
│   └── adrs/
├── docker-compose.yml
└── README.md

## Conseqüències

# Positives

Tot el projecte es troba dins d'un mateix repositori.
Facilita la coordinació entre frontend i backend.
És més senzill compartir configuracions i documentació.
Permet tenir la configuració de Docker centralitzada.
Facilita la gestió del projecte en un entorn de desenvolupament de classe.

# Negatives

El repositori pot créixer considerablement a mesura que augmenti el projecte.
Els canvis del frontend i backend es gestionen dins del mateix repositori.
Si el projecte creix molt, podria ser necessari separar alguns components en repositoris diferents.
